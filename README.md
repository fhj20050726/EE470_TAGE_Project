# EE470_TAGE_Project

This repository contains the files developed and modified for an EE470 course project that implements a TAGE (Tagged Geometric History Length) branch predictor in the BlackParrot RISC-V processor frontend.

Most of the project work was performed within the bp_fe/src/v directory. A new file, bp_fe_tage.sv, was created to implement the TAGE branch predictor and serves as a drop-in replacement for the original bp_fe_bht.sv module. A small modification was also made to bp_fe_pc_gen.sv so that the frontend uses predictions generated by the TAGE predictor. In addition, several global constants were modified within the bp_common/src/include directory to support a wider global branch history register required by the TAGE design.

The test programs used for simulation and evaluation are included in the my_test directory.

This repository is NOT a complete copy of the BlackParrot simulation environment. The original BlackParrot repository contains more than 300,000 files, while fewer than ten files were modified for this project. To keep the repository focused and manageable, only the files directly related to the TAGE implementation and evaluation have been included here. The complete black-parrot-sim repository can be found at https://github.com/black-parrot/black-parrot-sim.
