# EE470_TAGE_Project

**Overview
**
This repository contains the files developed and modified for an EE470 course project that implements a TAGE (Tagged Geometric History Length) branch predictor in the BlackParrot RISC-V processor frontend.

Rather than uploading the complete BlackParrot simulation environment, this repository includes only the files relevant to the TAGE implementation. The original BlackParrot simulation environment contains over 300,000 files, while fewer than ten files were modified for this project.


**Modified Files
**
Most project work was performed within the bp_fe/src/v directory.

TAGE Predictor Implementation

bp_fe_tage.sv:

Implements the complete TAGE branch predictor
Replaces the functionality of the original bp_fe_bht.sv
Contains the base predictor, tagged predictor tables, prediction selection logic, and predictor update logic
Frontend Integration

bp_fe_pc_gen.sv:

Modified to use the prediction output generated by the TAGE predictor
Allows the frontend to redirect instruction fetches based on TAGE predictions
Global History Configuration

Files inside bp_common/src/include were modified to increase the global branch history width required by the TAGE implementation.

**Test Programs
**
Simulation test programs are located in the: my_test directory.

These tests were used to evaluate branch prediction behavior and compare TAGE performance against the baseline BHT predictor.

**Repository Contents
**
This repository contains only the files necessary to understand, reproduce, and evaluate the TAGE implementation.

The complete BlackParrot simulation environment can be found at:

https://github.com/black-parrot/black-parrot-sim

This repository should be viewed as a collection of project modifications rather than a complete standalone copy of BlackParrot.
